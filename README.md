# Goose Game Kata

Including [3 parts](https://docs.google.com/document/d/1lYgVj3fmzC1JtRajOdEQ9r7Y6gm1WLxnZoq0h6vS9iA/edit?tab=t.0). Based on [Onboarding Basics](https://docs.google.com/document/d/1S1HgeKTFrm6JlGtvoea5DtAgY3KBms-n6CMQqEh0BfI/edit?tab=t.0). 

### To run:
1. Clone the repo
2. Run `npm install --save-dev jest` to install Jest (testing)
3. Run `npx jest` to run tests & `node goose-game.js` to see printing results
